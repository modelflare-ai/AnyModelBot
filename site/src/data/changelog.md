## 0.1.35 - 2026-11-14

### 新增

- **更简洁的侧栏与图标：** 通用操作图标统一使用 Heroicons。顶部保留收起、搜索和新建，定时移到文字导航；账户旁的更新按钮可直接下载，准备好后点击重启更新。
- **余额在设置中直接展示：** 在「设置 → 模型」顶部查看账户余额、Bot 额度和剩余百分比，可刷新或充值；移除侧栏的余额圆环和悬停卡片。

### 改进与修复

- **稳定的资源预览：** 网址输入和资源选择使用统一控件；右侧面板切换标签时保持宽度，手动调整后也不再跳变。修复侧栏收起后展开按钮可能无法点击的问题。
- **更准确的错误提示：** 额度预占失败归为余额不足，带前缀的错误也能识别状态码；提供与账户来源匹配的恢复入口，侧栏不再展示原始错误报文。
- **更清楚的电脑权限流程：** 单项权限使用单数标题，需要重新打开时直接显示主操作；重新打开前保留聊天与表单草稿，并保留待继续请求。
- **规则管理修复：** 切换开关或投递位置保留撤销资格；主人可跨会话管理规则，群聊成员的规则操作按身份隔离。频率按未来 30 天计算，高频建议改为每 3 小时或每天。
- **引导与文案统一：** 模板初始记忆和自动整理不再误计入「让它记住你」；统一模板示例、撤销提示、规则表单和启用说明，同步七种语言。

## 0.1.34 - 2026-11-14

### 新增

- **启动早期诊断：** 桌面版在申请单实例锁前就写入独立的 `startup-<时间>-<PID>.log`，记录系统版本、实际数据目录、锁结果和启动阶段。数据目录无法写入时，会尝试系统临时目录。
- **启动排查开关：** 使用 `--diagnose-startup` 启动时，如果未获得单实例锁，会显示诊断日志位置，方便排查无窗口退出。

### 改进与修复

- 重复启动发生在本机界面服务尚未就绪时，先保留窗口唤起请求，待就绪后再打开，避免过早创建窗口。
- 每次启动使用独立日志，主实例保留最近 20 份；正常的 `app.log` 不受第二次启动的日志轮转影响。
- 这是对 [#71](https://github.com/modelflare-ai/AnyModelBot/issues/71) 的诊断改进，尚不能确认 Win11 Insider Build 26300 的秒退根因。如果 `ELECTRON_RUN_AS_NODE` 让程序以 Node 模式启动，应用代码不会执行，仍需先检查这个环境变量。Windows 默认日志目录为 `%APPDATA%\anymodel bot\data\logs`，名称中有空格。

## 0.1.33 - 2026-11-14

### 新增

- **定时规则集中管理：** 侧栏新增「定时」页，查看所有机器人的规则和需要处理的事项。对话、任务面板和定时页共用开关；新机器人也能建规则，可以先关着。对话建好或修改规则后显示卡片，支持撤销；撤销创建后 10 分钟内可以恢复。
- **错过后补跑与群聊日报：** 日历类规则支持最长 12 小时内补跑最近一次，结果标明原定时间；「每隔」类不补跑。新增每月调度、接下来三次运行时间、时区和花费估算。群聊日报可选择要整理的应用内群聊，跨天补跑仍整理原定日期。
- **10 个机器人模板：** 新增模板入口，按写作、工作、学习等用途选择，预览人设、记忆与规则后创建；可比较适合的模型。模板规则默认关闭，打开时再补选发送位置和来源群聊。
- **右侧资源预览：** 对话、群聊和工作台里的文件与网页可以在右侧打开。支持 Markdown、文本与代码、PDF、图片和 HTML，并保留下载、系统打开和浏览器打开入口。
- **更适合右侧面板的工作台：** 官方 Bot 的项目导航会随可用宽度折叠；可展开工作台，再返回对话，保留当前编辑状态。
- **macOS 授权后继续：** 缺少电脑操作权限时只显示一张授权卡片，自动检测权限；符合条件时回到原会话继续未完成步骤，保留草稿。有新消息或等待超过 30 分钟时，由用户点「继续」。

### 改进与修复

- 改进 Modelflare 登录回跳、账户昵称与头像，以及首次使用引导；连接应用的列表、搜索和错误提示更清楚。
- 改进影视创作室的画布布局和美股研报的图表数据处理；PPT 大师、尽调助手等官方 Bot 同步适配新工作台。
- 规则结果显示来源，并遵循回复通知设置。可选择在插电且规则快到点时防止睡眠；此功能不能唤醒已经睡着或合盖的电脑。

## 0.1.31 - 2026-11-11

### 新增

- **连接应用：** 左下角头像菜单新增「连接应用」。把常用应用连上，机器人就能替你读写其中的内容。连一次，默认所有机器人都能用；也可以在机器人设置的「应用」里按机器人、按工具收窄。
- **内置海外应用：** GitHub、Notion、Linear、Atlassian（Jira 和 Confluence）、Canva，按提示一两步就能连上。
- **内置国内应用：** 飞书（读写云文档、查看群聊消息）、腾讯文档、钉钉、高德地图、语雀。中文界面把它们排在前面。
- **自定义连接器（MCP）：** 在应用页的「我的 MCP」里添加。粘贴链接、mcpServers JSON、`claude mcp add` 命令或本地启动命令就能识别，也可以用表单或 JSON 填写。支持远程服务和本地命令，认证方式有授权登录、请求头、查询参数和专属链接，最多 20 个。
- **改数据前先问你：** 只读的工具直接用。写入默认先在对话里问你，可以选「以后这个工具都允许」，之后能在机器人设置里撤销。删除和对外发送每次都问。只读权限的机器人不能写。
- **在对话里补上连接：** 任务要用还没连接的应用，或者授权过期、密钥失效时，对话里会出现一张卡片。点一下去连接或修复，完成后机器人接着做原来的任务。
- **右侧面板：** 原来的信息面板改成一排标签：概览、任务、记忆。官方 Bot 多一个「工作台」放它的专属界面，主区始终是对话。
- **侧栏分组：** 机器人、群聊和官方 Bot 可以放进自己建的分组。分组可以新建、改名、删除，也可以拖动排序。
- **官方 Bot 的专属形象：** PPT 大师、影视创作室、尽调助手和美股研报各有自己的头像和新封面。没换过头像的会自动换上。

### 改进与修复

- 设置里的「连接」改名为「聊天渠道」，只放聊天软件的账号。原来的 Notion 账号移到「连接应用」，不用重新授权。
- 原来的飞书消息账号也移到「连接应用」的飞书卡片下，不用重新授权；重新授权后还能读写云文档。
- Notion 的建页面、改页面现在也按上面的规则先问你。
- 应用的令牌、Key 和专属链接保存在单独的文件里，不在数据库里；界面和日志里都打码。
- macOS 上不再弹出钥匙串授权窗口：Modelflare 登录凭据改为和其他凭据一样，按文件权限保护。
- Modelflare 登录或连接失败时，提示里会写出具体的网络原因。
- 发现页的空白处可以拖动窗口了。
- 新建群聊后的引导改成三条用法要点和 2 到 3 条示例，点一下示例就填进输入框。
- 新建机器人页的模型设置改成和机器人设置里一样的一组，创建按钮与表单同宽。
- 头像菜单里「意见和反馈」下面的说明去掉了。

## 0.1.30 - 2026-11-10

### 新增

- **新用户注册送 $1 Bot 额度：** 登录页和填写 API Key 的页面写明了注册赠送；订阅 Modelflare 套餐另送套餐额度 10% 的 Bot 额度，额度卡片里也有说明。

- **搜索弹窗列出最近对话：** 还没输入时，按今天、昨天、前 7 天和更早列出最近的对话。

- 微信扫码登录要输入手机上的验证码时，输入后立刻验证，不再等半分钟；验证码不对会直接提示，输错太多次会自动换一张新二维码。
- 账户菜单和账户区一样宽，悬停时只有头像变深；设置页的分页导航撑满侧栏，账户区固定在底部。
- 带专属界面的 Bot 底部的示例改成一排单行胶囊，放不下时悬停可看全文。

## 0.1.29 - 2026-11-09

### 新增

- **自动下载更新（默认开启）：** 桌面安装版在后台下载新版本，下载完成后在侧栏和「设置 → 关于」提示「重启并更新」。可在「设置 → 常规」关闭自动下载，改为手动下载。
- 重启安装由你点击确认；有对话或后台任务正在运行时会等待你稍后操作，普通退出不会自动安装更新。
- 0.1.28 及更早版本需要先手动安装一次本版，之后才能使用应用内更新。支持 macOS、Windows 和 Linux AppImage；Docker 与源码部署仍手动升级。
- **登录后自动回到应用：** 在浏览器里同意授权后，页面会等应用真正连好再显示「登录成功」，并把你带回 AnyModelBot；没连上时直接说明原因。填写 API Key 的页面也可以直接改用 Modelflare 账号登录。
- **首次登录自动选好模型：** 还没有默认模型时，从你能用的模型里选一个支持工具、花费低的（优先 DeepSeek），让体验额度足够完成几轮常见任务；没有合适的模型时会说明原因，由你自己选。
- **macOS 电脑操作权限用到时才申请：** 机器人第一次要点击、输入或查看屏幕时，如果缺少「辅助功能」或「屏幕录制」权限，这一轮会停下，聊天里说明缺哪一项，并提供系统授权、打开对应设置页和重新检测；需要重新打开应用时，没发出的草稿会保留。
- **发现页封面：** 官方 Bot 换上按用途绘制的场景封面，跟随浅色 / 深色主题切换；精选 Bot 以大卡片展示。

### 改进与修复

- 出错提示更清楚：余额不足、凭据失效、模型不可用、请求过于频繁、网络失败等情况分别说明原因，并给出充值、换模型等对应操作；原始错误收在「错误详情」里，可以复制（已去除密钥）。同一个错误不再重复弹出，侧栏只显示「失败：原因」；重新发送前会说明将从头执行整个任务。尽调助手的任务报错也改为同样的折叠展示。
- 左下角账户区常驻显示余额和「充值」入口，余额较低时直接在这里提示，应用内不再另弹通知。账户菜单里可以提交反馈、检查更新和退出登录；有任务在运行时，退出前会先确认。使用自己的 API Key 时，这里也能登录 Modelflare，原有 Key 和配置照常保留。
- 上手清单：「连接常用聊天工具」可以选择你常用的渠道并直接打开对应设置，真正连上才算完成；「打个招呼」要收到一条正常回复才算完成；发送「记住……」后，清单几秒内就会更新。有草稿或任务正在运行时，引导不会自动弹出；全部完成后清单自动收起。
- 替换已有 Key 或更换模型来源后，会提醒你检查原有助手的模型设置；第一次配置不会提醒。
- 机器人设置连续保存只提示一次「已保存」；新建机器人时，模型设置默认折叠并显示跟随的默认模型，不再自动选中列表里的第一个模型；新建多助手协作时会说明用法，示例按成员生成。
- 搜索时点「发现」会回到发现页。
- 带专属界面的 Bot（尽调助手、PPT 大师、影视创作室、美股研报）底部的输入框与普通对话一致；示例改为一排卡片，长句不再被截断；最新回复按 Markdown 排版，长回复可以展开，也可以直接打开完整对话。
- 界面更清爽：去掉多余的分隔线和描边，输入框改为浅色填充；侧栏的「需要你」「发现」改为固定的导航行，待处理提示由数字改为蓝点（件数仍在悬停提示和读屏文字里）。
- 机器人头像边缘更干净：暗色界面上不再有一圈浅色毛边；小尺寸头像改用按尺寸预先缩好的图片，边缘更平滑。
- macOS 安装包发布前会校验 Developer ID 签名和苹果公证，未通过的不会发布。

- **ZIP 技能导入：** 在「机器人设置 → 技能」导入包含 `SKILL.md` 的 ZIP，预览名称和说明后添加。支持查看、启用、停用、删除，以及同名技能确认替换；脚本、参考资料和素材会一起保留。

## 0.1.19 - 2026-11-03

## 0.1.15 - 2026-11-02

### 新增

- **账号全局共用：** 微信、飞书、Telegram、Slack、Discord、Notion 的账号在 设置 › 连接 里加一次，所有机器人共用。每个服务可以加多个账号，还能起别名。
- **切换机器人：** 在聊天软件里发 `/bot` 看有哪些机器人，发一次 `/bot 名字` 就换过去，之后这个会话一直和它聊，不用每句都带。每个机器人也知道还有哪些同伴，你问起时它答得上来。
- **Telegram、Slack、Discord：** 填令牌就能连接，不需要公网地址，能收发图片和文件。
- **Notion：** 一键授权或用令牌连接。机器人能搜索、阅读、新建和修改页面，也能查数据库，不能删除页面。
- **读飞书消息：** 扫码授权后，可以对任何机器人说“看我第二个飞书的消息”。它用你的身份读会话、搜消息，只读。
- **飞书扫码添加：** 添加飞书聊天账号时，扫码就能创建应用，不用再手动填 App ID 和 Secret。

### 改进

- **联网搜索不再需要 DeepSeek Key：** 默认用免费搜索，也可以换成 Tavily、Exa、博查、智谱或自建的 SearXNG。
- **角色和岗位分开：** 头像只决定长相，选模板不会换头像。

### 变化

- 聊天渠道的配置从机器人的信息面板搬到了 设置 › 连接。老账号自动迁移，不用重新扫码，默认还是原来的机器人回复。
- 主人和允许名单现在跟着账号走，能用这个账号的人可以和任何机器人聊。删除机器人不再影响账号。
