# 匯入和管理技能

[简体中文](./skills.md) | 繁體中文（台灣） | [English](./skills_en.md) | [日本語](./skills_ja.md) | [한국어](./skills_ko.md) | [Русский](./skills_ru.md) | [Español](./skills_es.md) | [Português (Brasil)](./skills_pt.md) | [Türkçe](./skills_tr.md)

從 AnyModelBot 0.1.24 起，你可以把已有的工作流程作為 ZIP 技能包新增給機器人，例如寫週報、處理文件或整理資料。

## 匯入

1. 開啟目標機器人的設定，找到「技能」，點選「匯入 ZIP」。
2. 選擇本機 ZIP，核對技能名稱、說明和檔案數量；可展開查看完整說明。
3. 點選「新增技能」。機器人在相關任務中會按需載入這個技能。

每個 ZIP 包含一個技能。`SKILL.md` 可以在 ZIP 根目錄，也可以放在外層資料夾中。`scripts/`、`references/`、`assets/` 等配套檔案會一起保留。匯入不需要存取 GitHub，也不會自動執行包裡的安裝指令碼。

`SKILL.md` 需要 YAML 開頭和正文，例如：

```markdown
---
name: weekly-report
description: 根據使用者提供的工作記錄撰寫週報。
---

先整理已完成事項、遇到的問題和下週計畫，再按使用者要求的格式輸出。
```

名稱使用小寫英文字母、數字和單個連字元，最多 64 個字元。ZIP 最大 20 MB，解壓縮後最多 64 MB、2000 個項目；`SKILL.md` 最大 256 KB，每個機器人最多匯入 100 個技能。包含多個 `SKILL.md` 時，請把所需技能分別封裝。

## 從技能庫或 GitHub 安裝

- 開啟「應用程式與技能」的「技能」標籤，可以按用途分類、按作者瀏覽技能庫裡的技能；機器人設定的技能區也有「瀏覽技能庫」。點「複製安裝指令」，把這句發給任意機器人。
- 也可以直接把技能的 GitHub 連結（儲存庫、`/tree/<分支>/<路徑>` 目錄或 `SKILL.md` 檔案）發給機器人，說「裝一下這個」。
- 機器人會讀出技能的名稱、說明、來源、授權條款和檔案數，出一張確認卡片；點「安裝」才寫入，只裝到這個機器人上。聊天管道裡回覆卡片上的編號確認，飛書卡片上有按鈕。只有主人能安裝。
- 裝好的技能在清單裡標著來源「GitHub · 儲存庫」，「查看」裡有儲存庫、路徑、分支、安裝時的提交號和安裝時間。

## 從本機匯入（我的技能庫）

電腦上其他工具（如 Claude Code、Codex、Cursor、CodeBuddy）已經裝好的技能，可以一次匯入「我的技能庫」，再在機器人上開啟。

- 入口：大頭貼選單 ›「我的技能庫」›「從本機匯入…」，或機器人設定 ›「技能」›「從本機匯入…」。只在技能庫所在電腦的桌面版裡能尋找；網頁和遠端開啟時請繼續用 ZIP 或 GitHub 連結。
- 自動尋找這六個位置：`~/.codebuddy/skills/`、`~/.qwenworkcn/skills/`、`~/.agents/skills/`、`~/.claude/skills/`、`~/.cursor/skills/`、`~/.codex/skills/`。只看目錄和 `SKILL.md` 檔名，不讀正文，也不讀記憶和帳號。其他位置（如 `~/.workbuddy/skills/`、豆包的 `.user_skills/`、某個專案）點「選擇資料夾…」手動選；選專案時只查專案裡的 `.claude/skills/` 這類已知位置。主目錄、磁碟根和應用程式資料總目錄不會被整個搜尋。
- 候選項初始不勾選。勾選後點「下一步」才讀取所選技能，確認頁逐項說明：可匯入、已存在（內容完全相同，保持原狀態）、同名不同內容（預設跳過，可「另存一份」：呼叫名不變，顯示名加後綴）、不相容（寫明原因）。含指令碼的標「含指令碼，匯入不會執行」，有依賴的標「依賴尚未驗證」。
- 從機器人進入時預設勾選「匯入後在{機器人}上使用」；從庫進入預設只入庫。匯入後匯總已入庫、已開啟、跳過、失敗各幾項；開啟失敗（同名技能已開著、容量已滿）不影響已入庫的內容。
- 不會匯入：含疑似私人檔案（`.env`、`id_rsa`、`credentials.json`、`memory.md` 等）的、有連結指向所選位置之外的、帶目前環境無法等價保持的限制（如 `allowed-tools`、`hooks`）的、用到平台路徑變數（如 `${CLAUDE_PLUGIN_ROOT}`）或缺少引用檔案的技能。`disable-model-invocation`、`user-invocable` 照原樣保留；Codex 的 `allow_implicit_invocation: false` 會寫成 `disable-model-invocation: true`。
- 匯入是複製：來源不變，之後也不同步。庫裡每個技能只存一份，各機器人只記切換開關：在機器人設定中「從技能庫新增…」，或用切換開關開啟、關閉，只影響這個機器人。各機器人原來裝的 ZIP / GitHub 技能和「我存的」也都列在庫裡。
- 在「我的技能庫」裡點技能，可以查看內容和使用它的機器人。本機匯入的技能沒有機器人開著時，可以在「⋯」裡「從庫移除」，只刪除庫裡這一份。

## 使用、替換和刪除

- 技能只對新增它的機器人生效；同一機器人通過應用程式或聊天管道工作時共用這些技能（「我的技能」見下文）。
- 在技能清單中查看說明、啟用、停用或刪除。正在工作的機器人會等空閒後應用程式變更。
- 匯入成功的提示寫明什麼時候能用（下一則訊息起、目前任務結束後，或載入完後），下面一句「試著這樣說」，可以「填入輸入欄位」（切到這個機器人的對話）或「複製」；點按鈕或關閉後才收起。
- 重新匯入同名技能，預覽後點選「替換技能」即可更新。替換保留之前的啟用或停用狀態。
- 刪除技能會移除技能檔案，工作區中已經產生的檔案會保留。
- `media`、`computer-use`、`amb-app` 等內建名稱以及目錄 Bot 內附技能不能被匯入包覆寫。

技能執行階段仍使用機器人的權限。需要 Python、其他軟體或帳號連線的技能，必須具備對應環境；依賴其他用戶端專用工具的技能可能需要調整。技能格式相容不代表所有配套工具都已安裝。

## 在對話裡使用

- 在對話輸入欄位左邊點「+」›「技能與應用程式」，可以看到這個機器人現在能用的技能和應用程式。點一項，會把「用{名稱}幫我……」填進輸入欄位，補完再傳送；用不用由機器人自己判斷。
- 設定中每個技能的名稱旁標著「已生效」「下一則訊息起生效」或「載入中」，下面一行「試著這樣說」，點一下就填進這個機器人對話的輸入欄位。
- 機器人用上技能或應用程式時，回覆上方的處理過程會寫「正在使用技能 · {名稱}」，用到應用程式時每個工具一行「正在使用 {應用程式} · {工具}」（工具名優先用應用程式給的顯示名稱）；回覆結束後折成一行「已使用：…」，點開能看到完整過程。
- 問機器人「你有什麼技能」「你有什麼應用程式」，它會列出現在能用的項，各附一句可以照著說的話。
- `SKILL.md` 裡寫了 `disable-model-invocation: true` 的技能，機器人不會自己用，也不出現在「技能與應用程式」裡；在訊息裡寫 `/技能名` 才會用上。

## 把做成的事存成技能

和機器人把一件事做對之後，可以把做法存成「我的技能」，下次直接用，也能設成排程。

- 發起：在輸入欄位的「+」選單點「存成技能…」，或發 `/skill`，或直接說「存成技能」。只想存一部分時說「把步驟 3 存成技能」。機器人正在回覆時，會等這一輪結束再整理。
- 機器人先顯示「正在整理技能…」，然後出一張草稿卡：標題和檔名、什麼時候用、步驟、你糾正過的地方（可以取消勾選）、用到的應用程式和技能、「試著這樣說」。點「編輯」可以直接改技能檔案，改完會重新檢查。不點「儲存」不寫任何檔案；卡片 30 分鐘後過期。
- 金鑰（API Key、權杖、密碼、驗證碼、Cookie、身分證號）不會寫進技能，編輯時加回去也存不了。手機號、電子信箱、人名、群名和工作區以外的檔案路徑會標出來，預設「執行階段再問」：存成佔位，每次用之前先問你；選「保留」才把原文寫進技能。
- 任務沒做完也能存：草稿寫明卡在哪一步，存下來標為「未驗證」，用它成功做完一次後去掉標記。
- 標題相同、或機器人判斷是同一件事時，卡片會說改了幾處，可以「更新」或「另存新檔新技能」。更新會留下上一版，在「管理」裡可以還原。
- 「我的技能」全域一份、只存在本機，最多 100 個，和各機器人匯入的技能分開算。預設只在儲存它的機器人上開啟，在其他機器人設定的技能清單裡開啟切換開關就能用。只有主人能存；微信群、飛書群裡不能發起。
- 技能清單裡，「我的技能」的行有「查看」和「管理」。「管理」裡可以匯出 ZIP（只含這個技能自己的檔案，含保留的個人資訊時先提醒）、還原上一版、刪除。匯出的 ZIP 能在另一台電腦上作為本機 ZIP 技能匯入。
- 儲存成功後點「設成排程」，機器人問清時間，建一條「讓它做件事」的規則，每次按技能的最新版本執行。要操作電腦、生圖生影片或開背景任務的技能，以及未驗證的技能，不能設成排程。技能被刪除、在這個機器人上被關掉，或者更新、還原上一版後多了要先回答的內容、多了排程執行做不了的步驟、變成未驗證時，規則會暫停，出現在「排程」的「需要處理」裡。
- 技能超過 10 個時，清單頂部有搜尋框和「全部 / 我的技能 / GitHub / 本機 ZIP / 已關閉」篩選；處理過程裡的技能名可以點開看詳情。

## 資料存放

匯入包解開後儲存在資料目錄的 `skills/<機器人 ID>/`，啟用項在執行階段複製到 `dsh/<機器人 ID>/skills/`。匯入僅上傳到你正在使用的 AnyModelBot 執行個體；如果執行個體部署在伺服器上，檔案會存到那台伺服器。啟用技能的名稱和說明，以及使用時載入的正文或參考資料，會成為發給所選模型的上下文。詳見[資料與隱私](./privacy_zh-TW.md)。

「我的技能」儲存在資料目錄的 `my-skills/`，在哪個機器人上開啟，執行階段就複製到那個機器人的 `dsh/<機器人 ID>/skills/`。

從本機匯入的技能儲存在資料目錄的 `skill-library/`，在哪個機器人上開著，執行階段就複製到那個機器人的 `dsh/<機器人 ID>/skills/`。刪除機器人時，它裝的技能會留在「我的技能庫」裡。
