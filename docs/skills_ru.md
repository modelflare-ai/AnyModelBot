# Импорт навыков и управление ими

[简体中文](./skills.md) | [English](./skills_en.md) | [日本語](./skills_ja.md) | [한국어](./skills_ko.md) | Русский | [Español](./skills_es.md) | [Português (Brasil)](./skills_pt.md) | [Türkçe](./skills_tr.md)

Начиная с AnyModelBot 0.1.24, боту можно добавлять готовые рабочие инструкции в виде ZIP-пакетов: например, для еженедельных отчётов, обработки документов и сбора материалов.

## Импорт

1. Откройте настройки нужного бота и выберите «Навыки → Импорт ZIP».
2. Выберите локальный ZIP и проверьте имя, описание и число файлов. Разверните инструкции, чтобы прочитать их целиком.
3. Нажмите «Добавить навык». Бот сможет загружать его для подходящих задач.

Каждый ZIP содержит один навык. `SKILL.md` может находиться в корне ZIP или внутри внешней папки. Файлы из `scripts/`, `references/`, `assets/` и других папок сохраняются. Импорт не обращается к GitHub и не запускает установочные скрипты автоматически.

Для `SKILL.md` нужны заголовок YAML и текст инструкций:

```markdown
---
name: weekly-report
description: Составить еженедельный отчёт по рабочим заметкам пользователя.
---

Сгруппируй завершённые задачи, проблемы и планы на следующую неделю, затем используй формат пользователя.
```

Имя состоит из строчных английских букв, цифр и одиночных дефисов, не более 64 символов. Размер ZIP — до 20 МБ, после распаковки — до 64 МБ и 2000 записей. `SKILL.md` — до 256 КБ. Для каждого бота можно импортировать до 100 навыков. Если в ZIP несколько файлов `SKILL.md`, упакуйте навыки по отдельности.

## Установка из библиотеки навыков или GitHub

- На вкладке «Навыки» в разделе «Приложения и навыки» можно просматривать библиотеку навыков по назначению или автору; в разделе навыков в настройках бота тоже есть кнопка «Библиотека навыков». Нажмите «Скопировать запрос» и отправьте её любому боту.
- Можно и просто прислать боту ссылку на навык в GitHub (репозиторий, папку `/tree/<ветка>/<путь>` или файл `SKILL.md`) со словами «установи это».
- Бот прочитает название, описание, источник, лицензию и число файлов навыка и покажет карточку подтверждения. Пока вы не нажмёте «Установить», ничего не записывается, а навык ставится только этому боту. В чат-каналах подтвердите, ответив кодом с карточки; в карточках Feishu есть кнопки. Устанавливать навыки может только владелец.
- У установленных навыков в списке указан источник «GitHub · репозиторий», а в «Открыть» видны репозиторий, путь, ветка, коммит на момент установки и время установки.

## Импорт с этого компьютера (Моя библиотека навыков)

Навыки, уже установленные на компьютере для других инструментов (Claude Code, Codex, Cursor, CodeBuddy и т. п.), можно за один раз импортировать в «Мою библиотеку навыков», а затем включить в ботах.

- Где: меню аватара › «Моя библиотека навыков» › «Импортировать с этого компьютера…» или настройки бота › «Навыки» › «Импортировать с этого компьютера…». Искать можно только в настольном приложении на компьютере, где хранится библиотека; в браузере или удалённо по-прежнему используйте ZIP или ссылку GitHub.
- Автоматически просматриваются шесть мест: `~/.codebuddy/skills/`, `~/.qwenworkcn/skills/`, `~/.agents/skills/`, `~/.claude/skills/`, `~/.cursor/skills/`, `~/.codex/skills/`. Учитываются только папки и имена файлов `SKILL.md`; инструкции, память и учётные записи не читаются. Другие места (`~/.workbuddy/skills/`, `.user_skills/` у Doubao, отдельный проект) выберите через «Выбрать папку…»; в проекте проверяются только известные места вроде `.claude/skills/`. Домашняя папка, корень диска и общий каталог данных приложений целиком не просматриваются.
- Сначала ничего не выбрано. Навыки читаются только после выбора и нажатия «Далее». На странице проверки для каждого указано: можно импортировать, уже есть (содержимое полностью совпадает, состояние сохраняется), то же имя, другое содержимое (по умолчанию пропускается; «Сохранить отдельно» оставляет имя вызова и добавляет номер к показываемому названию) или несовместим (с причиной). Навыки со скриптами помечаются «Содержит скрипты; при импорте они не запускаются», с зависимостями — «Зависимости не проверены».
- Если открыть из бота, отмечено «Использовать в {бот} после импорта»; из библиотеки навыки только добавляются в библиотеку. После импорта показываются числа добавленных, включённых, пропущенных и неудачных. Если включить не удалось (навык с тем же именем уже включён или лимит заполнен), добавленное остаётся в библиотеке.
- Не импортируются навыки с возможными личными файлами (`.env`, `id_rsa`, `credentials.json`, `memory.md` и т. п.), ссылками за пределы выбранного места, ограничениями, которые приложение не может сохранить так же (`allowed-tools`, `hooks`), переменными путей платформы (`${CLAUDE_PLUGIN_ROOT}`) или отсутствующими файлами, на которые они ссылаются. `disable-model-invocation` и `user-invocable` сохраняются как есть; `allow_implicit_invocation: false` из Codex записывается как `disable-model-invocation: true`.
- Импорт — это копирование: источник не меняется и не синхронизируется. Каждый навык хранится в библиотеке в одном экземпляре, а бот хранит только переключатель: «Добавить из библиотеки…» в настройках бота или переключатель влияют только на этот бот. ZIP- и GitHub-навыки, установленные в ботах, и сохранённые вами навыки тоже есть в библиотеке.
- В «Моей библиотеке навыков» откройте навык, чтобы увидеть содержимое и использующие его боты. Если импортированный навык не включён ни в одном боте, «⋯» › «Убрать из библиотеки» удаляет только копию в библиотеке.

## Использование, замена и удаление

- Навык действует только для бота, которому вы его добавили (о «Моих навыках» см. ниже). Этот бот использует одни и те же навыки в приложении и чат-каналах.
- В списке можно просмотреть инструкции, включить, отключить или удалить навык. Изменения применяются, когда бот свободен.
- После импорта в уведомлении написано, когда навык заработает (со следующего сообщения, после текущей задачи или после загрузки), и есть пример **Попробуйте написать** с кнопками **Вставить в сообщение** (открывает чат этого бота) и **Копировать**. Уведомление остаётся, пока вы не нажмёте кнопку или не закроете его.
- Импортируйте навык с тем же именем повторно и после просмотра нажмите «Заменить навык». Состояние включения сохраняется.
- Удаление навыка оставляет созданные ранее результаты в рабочей папке.
- Встроенные имена `media`, `computer-use`, `amb-app` и навыки из комплекта ботов каталога нельзя перезаписать импортом.

Навыки используют существующие разрешения бота. Если нужны Python, другие программы или подключение аккаунта, подготовьте соответствующее окружение. Навыки, зависящие от инструментов другого клиента, могут требовать изменений. Совместимость формата не означает, что все нужные инструменты установлены.

## Использование в чате

- Нажмите **+** › **Навыки и приложения** слева от поля сообщения, чтобы увидеть навыки и приложения, которыми бот может пользоваться сейчас. Выберите один — в поле появится «С помощью {название} помоги мне…»; допишите фразу и отправьте. Использовать ли его, решает бот.
- В настройках рядом с названием каждого навыка написано **Работает**, **Заработает со следующего сообщения** или **Загружается**, а ниже — строка **Попробуйте написать**. Нажмите на неё, и пример появится в поле сообщения этого бота.
- Пока бот использует навык или приложение, в ходе работы над ответом видно «Использует навык · {название}», а для приложений — по строке на каждый инструмент: «Использует {приложение} · {инструмент}» (с отображаемым названием инструмента, если приложение его задаёт). Когда ответ готов, это сворачивается в строку «Использовано: …», которую можно развернуть и посмотреть все шаги.
- Спросите бота «Какие у тебя навыки?» или «Какие у тебя приложения?» — он перечислит доступные сейчас и к каждому даст пример фразы.
- Навык, в `SKILL.md` которого указано `disable-model-invocation: true`, бот сам не использует, и в **Навыки и приложения** его нет. Чтобы вызвать такой навык, напишите в сообщении `/имя-навыка`.

## Сохранить сделанное как навык

Когда бот сделал что-то правильно, способ можно сохранить в «Мои навыки», чтобы пользоваться им дальше или запускать по расписанию.

- Как начать: в меню «+» поля ввода выберите «Сохранить как навык…», отправьте `/skill` или просто скажите «сохранить как навык». Чтобы сохранить только часть, скажите «сохрани шаг 3 как навык». Если бот ещё отвечает, он соберёт навык после этого ответа.
- Бот показывает «Собираю навык…», а затем карточку черновика: название и имя файла, когда использовать, шаги, что вы поправили (можно снять отметку), используемые приложения и навыки, «Попробуйте сказать». «Изменить» открывает сам файл навыка; после правки он проверяется снова. Пока вы не нажмёте «Сохранить», ничего не записывается; карточка действует 30 минут.
- Секреты (API-ключи, токены, пароли, коды подтверждения, cookie, номера документов) в навык не попадают, и сохранить их не получится, даже если вписать вручную. Номера телефонов, адреса почты, имена, названия групп и пути к файлам вне рабочей папки выделяются, и по умолчанию выбрано «Спрашивать каждый раз»: они превращаются в заполнители, и бот спрашивает их перед каждым использованием. «Оставить» записывает исходный текст в навык.
- Можно сохранить и недоделанную задачу: в черновике будет сказано, где всё остановилось, а навык получит отметку «Не проверен», пока не выполнится успешно один раз.
- Если название совпадает или бот понимает, что это то же дело, карточка покажет, сколько мест изменилось, и предложит «Обновить» или «Сохранить как новый». При обновлении предыдущая версия остаётся, её можно вернуть в разделе «Управлять».
- «Мои навыки» — один общий список, он хранится только на этом компьютере, до 100 навыков, отдельно от навыков, импортированных в каждого бота. Сначала навык включён только для бота, который его сохранил; для другого бота включите переключатель в его списке навыков. Сохранять навыки может только владелец, и не из группы WeChat или Feishu.
- В списке навыков у строк «Моих навыков» есть «Открыть» и «Управлять». В «Управлять» можно экспортировать ZIP (только файлы этого навыка; если в нём оставлены личные данные, сначала будет напоминание), вернуть предыдущую версию или удалить навык. Экспортированный ZIP можно импортировать на другом компьютере как локальный ZIP-навык.
- После сохранения «Запускать по расписанию» — бот уточнит время и создаст правило «Выполнить задачу», которое всегда использует последнюю версию навыка. Навыки, которым нужно управление компьютером, создание изображений и видео или фоновые задачи, а также непроверенные навыки запускать по расписанию нельзя. Если навык удалили, выключили для этого бота, или после обновления либо возврата версии появились новые вопросы, шаги, недоступные по расписанию, или навык стал непроверенным, правило приостанавливается и появляется в разделе «По расписанию» → «Требуют внимания».
- Когда навыков больше 10, над списком появляются поиск и фильтры «Все / Мои навыки / GitHub / Локальный ZIP / Выключены». Названия навыков в ходе работы открывают сведения о навыке.

## Хранение

Распакованные пакеты хранятся в `skills/<ID бота>/` внутри каталога данных. Включённые навыки копируются в `dsh/<ID бота>/skills/` для выполнения. Импорт передаёт файлы только используемому экземпляру AnyModelBot; при серверном развёртывании они сохраняются на этом сервере. Имена и описания включённых навыков, а также прочитанные при работе инструкции и справочные материалы становятся контекстом для выбранной модели. См. [Данные и конфиденциальность](./privacy_ru.md).

«Мои навыки» хранятся в папке `my-skills/` каталога данных и при запуске копируются в `dsh/<ID бота>/skills/` каждого бота, для которого они включены.

Навыки, импортированные с этого компьютера, хранятся в папке `skill-library/` каталога данных и при запуске копируются в `dsh/<ID бота>/skills/` каждого бота, где они включены. При удалении бота установленные в нём навыки остаются в «Моей библиотеке навыков».
