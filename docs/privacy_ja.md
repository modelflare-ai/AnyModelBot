# データとプライバシー

[简体中文](./privacy.md) | [繁體中文（台灣）](./privacy_zh-TW.md) | [English](./privacy_en.md) | 日本語 | [한국어](./privacy_ko.md) | [Русский](./privacy_ru.md) | [Español](./privacy_es.md) | [Português (Brasil)](./privacy_pt.md) | [Türkçe](./privacy_tr.md)

**要点：** 会話、記憶、ファイル、キーは端末に保存します。モデルへ送る内容は選択した提供元に届きます。公式 API キーの場合は直接、それ以外は Modelflare を経由します。データに一切のリスクがないとは主張しません。モデルに送るものは端末の外に出ます。

保存するデータと場所、外部への送信、削除方法を説明します。お問い合わせは [support@anymodel.bot](mailto:support@anymodel.bot) へ。

## ローカルコンソールのアクセス制御

- 既定では `127.0.0.1:3600` で待ち受け、ネットワークやインターネットからはアクセスできません。
- デスクトップは起動ごとにランダムなアクセストークンを生成し、ほかのローカルプログラムが管理 API を直接呼べないようにします。
- 管理 API にはループバックアドレスでも常にアクセストークンが必要です。デスクトップ版のトークンはメモリー上だけにあります。コマンドライン版と Docker は、設定されていなければ自動で作り、データディレクトリの `ui-token` に保存します（Docker：`docker exec amb cat /data/ui-token`）。コマンドライン版をターミナルから起動すると、トークン付きのアドレスを一度表示します。
- ポート 3600 をインターネットに直接公開しないでください。遠隔アクセスには、自分で管理する VPN または認証付きリバースプロキシを使ってください。

## Modelflare へのログイン

- RFC 8252 に従うネイティブアプリとして、OIDC 認可コードフローと PKCE（RFC 7636）を使います。AnyModelBot はクライアントシークレットを持たない公開クライアントで、認可結果は一時的なループバックポートへ返されます。
- ログインは modelflare.dev で行い、AnyModelBot がパスワードを見ることはありません。
- Modelflare プロフィールの認可済みアプリから、いつでも端末の認可を取り消せます。アプリのログアウトも認可を取り消し、端末とボットに発行したキーを削除します。

## モデルのリクエストと Modelflare

- 内蔵 magpie ゲートウェイから Modelflare を経由し、選択した提供元にリクエストを送ります。
- プロンプト、会話の文脈、使用する記憶、ファイル内容、ツール結果、コンピューター操作時のスクリーンショットなど、回答に必要な内容が含まれます。
- 出所の識別用に `X-Modelflare-Skill: anymodel-bot/<version>` ヘッダーを付けます。アプリから開く Modelflare のリンクには `utm_source=anymodelbot` が含まれます。 アプリからチャージページを開くとき、URL の `#` の後ろにログイン時の ID トークンにあるアカウント識別子（`#amb_account=…`、秘密情報ではありません）を付け、Modelflare のページがブラウザーで同じアカウントにログインしているか確認します。`#` 以降はサーバー、CDN、解析スクリプトに送られません。「キー設定を切り替えました」の通知は、端末内でランダムなソルトを使ってキーの HMAC を計算し比較するだけで、キーやその要約を保存・送信しません。
- Modelflare はリクエストログを保持します。項目と期間は [トラストセンター](https://modelflare.dev/trust?utm_source=anymodelbot&utm_campaign=amb_readme) を参照してください。モデル提供元のデータ取り扱いは各社の規約に従います。

## 自分の公式 API キーを使う場合

- 初回画面または「設定 → モデル」で OpenAI、Anthropic などの公式キーを入力すると、その提供元へのリクエストは内蔵ゲートウェイから直接送られ、Modelflare を経由せず、`X-Modelflare-Skill` ヘッダーも付きません。内容の保持は各提供元の規約に従います。
- 提供元のアドレスはアプリに固定されており、画面や API から変更できないため、キーが他の宛先へ送られることはありません。キーはゲートウェイの隔離された設定（権限 600）にのみ保存され、ログやコマンドライン引数には出ず、画面には末尾 4 文字だけが表示されます。
- 公式キーのみでログインしていない場合、アプリは Modelflare のアカウントデータや価格一覧を読み取りません。キーの入力時に確認のためモデル一覧を一度読み取り、その後は一覧を更新するため 1 時間ごとに読み取ります。
- 内蔵ゲートウェイは公開のモデルカタログ（コンテキスト長、参考価格）を `models.dev` から読み取ります。この通信はダウンロードのみで、キーや会話の内容は含みません。
- 画像と動画の生成は Modelflare 経由でのみ利用できます。

## テレメトリー

- 同梱の Cua Driver は `CUA_TELEMETRY_ENABLED=0` と `CUA_DRIVER_RS_TELEMETRY_ENABLED=0` でテレメトリーを無効にします。
- 内蔵 magpie は自動更新とアカウント検出を無効にして動かし、端末上の他の AI ツールの認証情報を読みません。
- AnyModelBot 本体（`src`、`electron`、`ui`、`scripts`、`dsh-runtime/plugins`）には解析やテレメトリーの送信処理がありません。telemetry、analytics、sentry、posthog、mixpanel の検索で見つかるのは上記 Cua の環境変数 2 個だけです。
- 同梱の第三者コンポーネントは各自の文書に従って動作します。ここではそれらの動作を保証しません。

## アプリが行うその他の通信

モデルのリクエスト以外に、次の通信を行います。

- Modelflare のモデル一覧、残高、使用量、通知の取得（modelflare.dev のアカウントデータ）。
- 「要望とフィードバック」から送信したとき（利用シーンと提案・問題の報告・法人・提携のいずれか）、書いた内容、補足したシーンや法人情報、選んだ役割、開いた場所、バージョンとシステム情報、添付を選んだエラーとログ（キーは `***` に置換）を modelflare.dev に送り、Modelflare アカウントの非公開チケットとして登録します。返信はメールで届き、Modelflare のチケットページでも確認できます。送信前に送信内容をすべて確認でき、会話内容やスクリーンショットは添付されません。連絡先は既定では送りません。「もう少し話を聞かせてもらえますか？」を開いて「このフィードバックについてのみ連絡を受けることに同意します」を選び、アカウントのメールを選ぶかメールアドレス・WeChat ID を入力したときだけ、その送信に含まれ、そのフィードバックのやり取りにのみ使われます。ウィンドウを閉じたり、ログインやアカウント切り替えをしたりすると、改めて確認します。下書きはこの端末のデータフォルダにのみ保存され（アカウントごと、本人だけが読める、ボットは読めない、7 日間使わないと削除）、クラウドには同期しません。Modelflare にログインしていない場合や外部ゲートウェイの場合はアプリ内でチケットを作れないため、メールまたは GitHub（公開）から自分で送れます。その写しには連絡先や法人情報は含まれません。「Modelflare に問い合わせ」は入力内容を一切付けずに商談の問い合わせページを開きます。
- 画像・動画生成時に docs.modelflare.dev からリクエスト形式を取得。
- WeChat：`ilinkai.weixin.qq.com` との通信、および送られた画像・ファイルの WeChat CDN からの取得。
- Feishu：Feishu Open Platform との持続接続。
- Telegram、Slack、Discord：接続後に `api.telegram.org`、`slack.com`、`discord.com` と各ファイル配信先を利用してメッセージやファイルを送受信。
- Windows でエージェントが有効かつ使用可能な PowerShell 7 がない場合、Microsoft の公式配布先から PowerShell 7 を取得（`AMB_PWSH_AUTO_INSTALL=0` で停止可能。[開発ガイド](./development_ja.md) 参照）。
- デスクトップインストール版は起動後と6時間ごとに GitHub で更新を確認し、標準では更新ファイルをバックグラウンドでダウンロードします。「設定 → 一般」で自動ダウンロードを無効にできます。リクエストにアカウントの認証情報や会話内容は含みません。インストールには「再起動して更新」のクリックが必要で、実行中のタスクがない場合に行います。
- まだインストールしていない新しいバージョンの「更新内容」を開いたときは、そのバージョンの変更履歴を GitHub（`raw.githubusercontent.com`）から読み込みます。開いたときだけリクエストし、アカウントの認証情報や会話内容は含みません。インストール済みのバージョンの変更履歴はアプリに同梱されており、ネットワークを使いません。
- `AMB_CATALOG_URL` を明示的に設定してリモートの Bot カタログを使う場合にのみ、一覧と必要なパッケージを取得し、署名とハッシュを検証します。あなたのデータはアップロードしません。標準の公式 Bot カタログ、画面、サンプルデータ、スキルはアプリに同梱されており、表示やインストール時にこれらの通信は発生しません。

## コンピューター操作とスクリーンショット

- 画面の読み取りではスクリーンショットを撮り、モデルリクエストの一部として画像対応モデルへ送ります。
- 既定では操作を自動実行します。ボット設定 → コンピューター操作で画面変更前に確認する設定にできます。画面の読み取りは引き続き自動です。
- 読み取り専用のボットには読み取りツールだけを提供します。

## チャネル

- WeChat、Feishu、Telegram、Slack、Discord で交わすメッセージは各プラットフォームのサーバーを通り、それぞれのプライバシーポリシーが適用されます。
- 既定では所有者と許可した人だけが会話できます。他者のメッセージはモデルに渡さず、利用リクエストとして記録します（[開発ガイド](./development_ja.md#ボットを利用できる人) 参照）。

## データの削除

1. AnyModelBot を終了します（トレイメニュー → 終了）。
2. 上の表にあるデータディレクトリを削除します。Docker：`docker rm -f amb && docker volume rm amb-data`。
3. Modelflare プロフィールの認可済みアプリから AnyModelBot の認可を取り消します。
4. 必要に応じて Feishu Open Platform のアプリ（スキャンで作成したものも含む）を無効にし、WeChat のボット連携を解除します。Telegram（@BotFather）、Slack、Discord で作ったボットも削除し、Notion では AnyModelBot との接続を切って作成済みトークンを削除します。
