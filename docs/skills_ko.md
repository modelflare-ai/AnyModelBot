# 스킬 가져오기와 관리

[简体中文](./skills.md) | [English](./skills_en.md) | [日本語](./skills_ja.md) | 한국어 | [Русский](./skills_ru.md) | [Español](./skills_es.md) | [Português (Brasil)](./skills_pt.md) | [Türkçe](./skills_tr.md)

AnyModelBot 0.1.24부터 주간 보고서, 문서 처리, 자료 정리 등의 작업 방법을 ZIP 스킬 패키지로 봇에 추가할 수 있습니다.

## 가져오기

1. 대상 봇의 설정에서 「스킬 → ZIP 가져오기」를 선택합니다.
2. 로컬 ZIP을 선택하고 이름, 설명, 파일 수를 확인합니다. 설명을 펼치면 전체 지침을 볼 수 있습니다.
3. 「스킬 추가」를 누릅니다. 봇은 관련 작업에서 필요할 때 스킬을 불러옵니다.

ZIP마다 스킬 하나를 넣습니다. `SKILL.md`는 ZIP의 최상위나 바깥 폴더 안에 있어도 됩니다. `scripts/`, `references/`, `assets/` 등의 파일도 함께 유지됩니다. 가져올 때 GitHub에 접속하거나 설치 스크립트를 자동 실행하지 않습니다.

`SKILL.md`에는 YAML 헤더와 지침 본문이 필요합니다.

```markdown
---
name: weekly-report
description: 사용자의 업무 메모로 주간 보고서를 작성한다.
---

완료한 업무, 문제점, 다음 주 계획을 정리하고 사용자가 지정한 형식으로 작성한다.
```

이름은 영문 소문자, 숫자, 단일 하이픈으로 구성하며 최대 64자입니다. ZIP은 최대 20 MB, 압축 해제 후 최대 64 MB 및 2,000개 항목, `SKILL.md`는 최대 256 KB입니다. 봇당 최대 100개 스킬을 가져올 수 있습니다. `SKILL.md`가 여러 개라면 스킬별로 ZIP을 만들어 주세요.

## 스킬 라이브러리나 GitHub에서 설치하기

- "앱과 스킬"의 "스킬" 탭에서 스킬 라이브러리를 용도별·작성자별로 볼 수 있습니다. 봇 설정의 스킬 영역에도 "스킬 라이브러리 보기"가 있습니다. "설치 문구 복사"를 눌러 그 문장을 아무 봇에게 보내세요.
- 스킬의 GitHub 링크(저장소, `/tree/<브랜치>/<경로>` 폴더 또는 `SKILL.md` 파일)를 봇에게 보내고 "이거 설치해 줘"라고 말해도 됩니다.
- 봇이 스킬의 이름, 설명, 출처, 라이선스, 파일 수를 읽고 확인 카드를 보여 줍니다. "설치"를 누르기 전에는 아무것도 쓰지 않으며, 그 봇에만 설치됩니다. 채팅 채널에서는 카드의 번호로 답해 확인하고, Feishu 카드에는 버튼이 있습니다. 주인만 설치할 수 있습니다.
- 설치한 스킬은 목록에 출처 "GitHub · 저장소"로 표시되며, "보기"에서 저장소, 경로, 브랜치, 설치 당시 커밋과 설치 시각을 볼 수 있습니다.

## 이 컴퓨터에서 가져오기 (내 스킬 라이브러리)

컴퓨터의 다른 도구(Claude Code, Codex, Cursor, CodeBuddy 등)에 이미 설치된 스킬을 한 번에 내 스킬 라이브러리로 가져와 봇에서 켤 수 있습니다.

- 위치: 프로필 메뉴 › 「내 스킬 라이브러리」 › 「이 컴퓨터에서 가져오기…」, 또는 봇 설정 › 「스킬」 › 「이 컴퓨터에서 가져오기…」. 라이브러리가 있는 컴퓨터의 데스크톱 앱에서만 찾을 수 있습니다. 브라우저나 원격에서는 ZIP이나 GitHub 링크를 계속 사용하세요.
- 자동으로 찾는 곳은 여섯 군데입니다: `~/.codebuddy/skills/`, `~/.qwenworkcn/skills/`, `~/.agents/skills/`, `~/.claude/skills/`, `~/.cursor/skills/`, `~/.codex/skills/`. 폴더와 `SKILL.md` 파일 이름만 보고, 본문이나 기억, 계정은 읽지 않습니다. 다른 위치(`~/.workbuddy/skills/`, Doubao의 `.user_skills/`, 특정 프로젝트 등)는 「폴더 선택…」으로 직접 고릅니다. 프로젝트는 `.claude/skills/` 같은 알려진 위치만 확인합니다. 홈 폴더, 디스크 루트, 앱 데이터 전체는 통째로 찾지 않습니다.
- 후보는 처음에 아무것도 선택되어 있지 않습니다. 선택하고 「다음」을 눌러야 읽습니다. 확인 화면은 항목마다 가져올 수 있음 / 이미 있음(내용이 완전히 같음, 상태 유지) / 이름은 같고 내용이 다름(기본은 건너뛰기, 「따로 저장」을 고르면 호출 이름은 그대로 두고 표시 이름에 번호를 붙임) / 호환되지 않음(이유 표시)을 알려 줍니다. 스크립트가 있으면 「스크립트가 있습니다. 가져올 때 실행하지 않습니다」, 의존성이 있으면 「의존성 미확인」이라고 표시합니다.
- 봇에서 열면 「가져온 뒤 {봇}에서 사용」이 기본으로 선택되고, 라이브러리에서 열면 라이브러리에만 추가합니다. 가져온 뒤 추가, 켜짐, 건너뜀, 실패 개수를 함께 보여 줍니다. 켜지 못해도(같은 이름의 스킬이 켜져 있거나 용량이 가득 참) 추가한 내용은 라이브러리에 남습니다.
- 가져오지 않는 것: 개인 파일로 보이는 항목(`.env`, `id_rsa`, `credentials.json`, `memory.md` 등), 선택한 위치 밖을 가리키는 링크, 이 앱에서 똑같이 유지할 수 없는 제한(`allowed-tools`, `hooks` 등), 플랫폼 경로 변수(`${CLAUDE_PLUGIN_ROOT}` 등), 참조한 파일이 없는 스킬. `disable-model-invocation`과 `user-invocable`은 그대로 유지하며, Codex의 `allow_implicit_invocation: false`는 `disable-model-invocation: true`로 기록합니다.
- 가져오기는 복사입니다. 원본은 바뀌지 않고 동기화하지도 않습니다. 라이브러리에는 스킬마다 한 벌만 있고 봇은 켜짐/꺼짐만 기억합니다. 봇 설정의 「라이브러리에서 추가…」나 스위치는 그 봇에만 영향을 줍니다. 봇에 설치한 ZIP / GitHub 스킬과 내가 저장한 스킬도 라이브러리에 함께 표시됩니다.
- 내 스킬 라이브러리에서 스킬을 열면 내용과 사용하는 봇을 볼 수 있습니다. 가져온 스킬을 켠 봇이 없으면 「⋯」 › 「라이브러리에서 제거」로 라이브러리 사본만 지울 수 있습니다.

## 사용, 교체, 삭제

- 스킬은 추가한 봇에만 적용됩니다(내 스킬은 아래 참고). 같은 봇은 앱과 채팅 채널에서 같은 스킬을 사용합니다.
- 목록에서 설명 보기, 활성화, 비활성화, 삭제를 할 수 있습니다. 변경은 봇이 대기 상태가 된 후 적용됩니다.
- 가져오기에 성공하면 언제부터 쓸 수 있는지(다음 메시지부터, 현재 작업이 끝난 뒤, 또는 불러오기가 끝난 뒤)와 **이렇게 말해 보세요** 예시가 표시되고, **입력창에 넣기**(이 봇의 대화를 엽니다)나 **복사**를 누를 수 있습니다. 버튼을 누르거나 닫을 때까지 표시됩니다.
- 같은 이름의 스킬을 다시 가져와 확인한 후 「스킬 교체」를 누르면 갱신됩니다. 기존 활성화 상태는 유지됩니다.
- 스킬을 삭제해도 작업 공간에 이미 생성된 결과물은 유지됩니다.
- `media`, `computer-use`, `amb-app` 등의 내장 스킬과 카탈로그 Bot에 포함된 스킬은 덮어쓸 수 없습니다.

스킬은 봇의 기존 권한으로 실행됩니다. Python, 추가 소프트웨어, 계정 연결이 필요한 스킬은 해당 환경을 갖춰야 합니다. 다른 클라이언트 전용 도구에 의존한다면 수정이 필요할 수 있습니다. 형식 호환이 모든 도구의 설치를 의미하지는 않습니다.

## 대화에서 사용하기

- 메시지 입력창 왼쪽의 **+** › **스킬 및 앱**을 열면 이 봇이 지금 사용할 수 있는 스킬과 앱이 보입니다. 항목을 누르면 "{이름}을(를) 써서 …"가 입력창에 들어가니, 나머지를 채워서 보내세요. 사용할지는 봇이 판단합니다.
- 설정의 스킬 목록에는 이름 옆에 **적용됨**, **다음 메시지부터 적용**, **불러오는 중** 중 하나가 표시되고, 그 아래에 **이렇게 말해 보세요** 예시가 있습니다. 예시를 누르면 이 봇의 입력창에 들어갑니다.
- 봇이 스킬이나 앱을 쓰는 동안 답장 위의 처리 과정에 "스킬 사용 중 · {이름}"이 표시되고, 앱은 도구마다 한 줄씩 "{앱} · {도구} 사용 중"으로 표시됩니다(앱이 표시 이름을 제공하면 그 이름을 씁니다). 답장이 끝나면 "사용함: …" 한 줄로 접히며, 펼치면 전체 단계를 볼 수 있습니다.
- 봇에게 "어떤 스킬이 있어?", "어떤 앱이 있어?"라고 물으면 지금 쓸 수 있는 항목을 바로 보낼 수 있는 예시와 함께 알려 줍니다.
- `SKILL.md`에 `disable-model-invocation: true`가 적힌 스킬은 봇이 스스로 쓰지 않고 **스킬 및 앱**에도 나오지 않습니다. 메시지에 `/스킬이름`을 쓰면 사용됩니다.

## 한 일을 스킬로 저장하기

봇과 함께 제대로 해낸 일은 그 방법을 "내 스킬"에 저장해 다음에 바로 쓰거나 예약 실행으로 설정할 수 있습니다.

- 시작하기: 입력창의 "+" 메뉴에서 "스킬로 저장…"을 누르거나, `/skill`을 보내거나, "스킬로 저장"이라고 말하세요. 일부만 남기려면 "3단계를 스킬로 저장"이라고 말하면 됩니다. 봇이 답변 중이면 이번 답변이 끝난 뒤 정리합니다.
- 봇은 "스킬을 정리하는 중…"을 보여 준 뒤 초안 카드를 띄웁니다: 제목과 파일 이름, 사용 시점, 단계, 직접 바로잡은 내용(체크 해제 가능), 사용하는 앱과 스킬, "이렇게 말해 보세요". "편집"을 누르면 스킬 파일을 직접 고칠 수 있고, 완료하면 다시 확인합니다. "저장"을 누르기 전에는 아무 파일도 쓰지 않으며, 카드는 30분 뒤 만료됩니다.
- 비밀 정보(API 키, 토큰, 비밀번호, 인증 코드, 쿠키, 주민등록번호 등 신분증 번호)는 스킬에 들어가지 않고, 편집으로 다시 넣으면 저장할 수 없습니다. 전화번호, 이메일, 이름, 그룹 이름, 작업 공간 밖의 파일 경로는 강조 표시되며 기본값은 "사용할 때마다 묻기"입니다. 자리 표시자로 저장되어 쓸 때마다 먼저 묻고, "남기기"를 고르면 원문을 스킬에 넣습니다.
- 작업을 끝내지 못했어도 저장할 수 있습니다. 초안에 어느 단계에서 멈췄는지 적고 "미검증"으로 저장하며, 이 스킬로 한 번 끝까지 해내면 표시가 사라집니다.
- 제목이 같거나 봇이 같은 작업이라고 판단하면 카드에 바뀐 곳의 수를 보여 주고 "업데이트" 또는 "새 스킬로 저장"을 고를 수 있습니다. 업데이트하면 이전 버전이 남아 "관리"에서 되돌릴 수 있습니다.
- 내 스킬은 전체에서 하나의 목록으로 이 컴퓨터에만 저장되며 최대 100개입니다. 봇마다 가져온 스킬과는 따로 셉니다. 처음에는 저장한 봇에서만 켜지고, 다른 봇에서는 스킬 목록의 스위치를 켜면 쓸 수 있습니다. 주인만 저장할 수 있고, 위챗·Feishu 그룹에서는 시작할 수 없습니다.
- 스킬 목록에서 내 스킬 행에는 "보기"와 "관리"가 있습니다. "관리"에서 ZIP 내보내기(이 스킬의 파일만 포함, 남긴 개인정보가 있으면 먼저 알림), 이전 버전으로 되돌리기, 삭제를 할 수 있습니다. 내보낸 ZIP은 다른 컴퓨터에서 로컬 ZIP 스킬로 가져올 수 있습니다.
- 저장한 뒤 "예약 실행으로 설정"을 누르면 봇이 시간을 확인하고 "작업 수행" 규칙을 만들며, 매번 스킬의 최신 버전으로 실행합니다. 컴퓨터 조작, 이미지·동영상 생성, 백그라운드 작업이 필요한 스킬과 미검증 스킬은 예약 실행으로 설정할 수 없습니다. 스킬이 삭제되거나, 그 봇에서 꺼지거나, 업데이트·되돌리기 뒤에 먼저 답해야 할 내용이나 예약 실행으로 할 수 없는 단계가 늘거나, 미검증이 되면 규칙이 일시 중지되고 "예약"의 "확인 필요"에 나타납니다.
- 스킬이 10개를 넘으면 목록 위에 검색창과 "전체 / 내 스킬 / GitHub / 로컬 ZIP / 꺼짐" 필터가 나타납니다. 처리 과정에 나오는 스킬 이름을 누르면 세부정보를 볼 수 있습니다.

## 저장 위치

압축을 푼 패키지는 데이터 디렉터리의 `skills/<봇 ID>/`에 저장하고 활성화된 스킬을 실행용 `dsh/<봇 ID>/skills/`로 복사합니다. 가져오기는 현재 사용하는 AnyModelBot 인스턴스로만 전송됩니다. 서버에서 운영한다면 파일은 그 서버에 저장됩니다. 활성화된 스킬의 이름과 설명, 사용 시 읽은 본문이나 참고 자료는 선택한 모델에 보내는 문맥에 포함됩니다. [데이터 및 개인정보](./privacy_ko.md)를 참고하세요.

내 스킬은 데이터 디렉터리의 `my-skills/`에 저장되며, 켜 둔 봇마다 실행할 때 `dsh/<봇 ID>/skills/`로 복사됩니다.

이 컴퓨터에서 가져온 스킬은 데이터 디렉터리의 `skill-library/`에 저장되며, 켜 둔 봇마다 실행할 때 `dsh/<봇 ID>/skills/`로 복사됩니다. 봇을 삭제해도 그 봇에 설치했던 스킬은 내 스킬 라이브러리에 남습니다.
