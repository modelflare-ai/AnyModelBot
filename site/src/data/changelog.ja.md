## 0.1.48 - 2026-11-25

### 新機能

- **このパソコンからスキルを取り込む：** デスクトップアプリで、パソコン上のほかのツール（Claude Code、Codex、Cursor、CodeBuddy など）にインストール済みのスキルをまとめて取り込めます。`~/.claude/skills/` など 6 つのよくある場所を自動で探し、「フォルダを選択…」でスキルのフォルダやプロジェクトも選べます。選んで「次へ」を押すまではフォルダとファイル名しか見ません。確認画面では、取り込めます／すでにあります／同じ名前で内容が異なります（既定はスキップ、別に保存も可）／非対応とその理由を項目ごとに示します。取り込み時にスクリプトは実行せず、個人的なファイルの可能性があるものや、このアプリで同じように保てない呼び出し制限のあるスキルは取り込みません。ボット設定から開いた場合は、取り込んだスキルがそのボットで既定でオンになります。
- **マイスキルライブラリ：** アバターメニューに「マイスキルライブラリ」を追加しました。このパソコンのスキルを 1 つずつ保存し、検索や内容、使っているボットの確認ができます。ボット設定の「スキル」には「ライブラリから追加…」が加わり、スイッチはそのボットにだけ影響します。ZIP や GitHub でインストールしたスキルと自分で保存したスキルも、取り込み直さずにライブラリに並びます。

### 改善と修正

- **共有スキルを変える前に影響先を表示：** 複数のボットが使うスキルを ZIP や GitHub のリンクで置き換えるとき、または複数のボットでオンのマイスキルを更新するとき、ほかに反映されるボットを示します。
- **ボットを削除してもスキルは消えません：** そのボットに入れていたスキルはマイスキルライブラリに残り、別のボットに追加することも、ライブラリから削除することもできます。

## 0.1.47 - 2026-11-23

### 新機能

- **画像を画像生成の参照に使う：** Modelflare アカウントでログインし、ボットとの 1 対 1 チャットに画像を追加すると、添付数の横に「画像生成の参照に使う」スイッチ（既定はオフ）が出ます。オンにすると、そのメッセージの画像が表示順に参照となり、右下で選んだモデルが画像を生成して同じ会話に返します。画像を追加しただけで有料の生成が始まることはありません。現在のモデルが対応していない、機能をまだ確認できない、画像が枚数・形式・サイズの制限を超えているときは、入力欄の上に理由を表示し、その中の「モデルを切り替えてください」からいつものモデル選択を開けます。費用の確認はこれまでどおり（毎回、または見積もりが $0.5 を超えるとき）で、結果が確認できないときは自動で再試行しません。Modelflare からモデルの機能情報を得る必要があり、確認できないときは送信しません。独自の API キーではまだ使えません。
- **モデル選択で画像生成モデルを選ぶ：** ログイン中は、右下のモデル選択にアカウントで使える画像生成モデルも並びます。選んだら欲しい画像を書くだけで生成でき、会話モデルは使いません。

### 改善と修正

- **画像生成は選択中のモデルだけを使用：** ログイン中にボットへ言葉で画像を頼んだときも、右下で選んだモデルだけを使います。そのモデルが画像を生成できない、または機能を確認できないときは理由を伝えて切り替えを促し、別の既定の画像モデルには切り替えません（ログイン中は設定の「既定の画像モデル」を表示しません）。API キーだけで接続している場合は変わりません。

## 0.1.46 - 2026-11-22

### 新機能

- **作業フォルダー：** デスクトップ版では、入力欄の上でフォルダーを選ぶと、ボットがその場所のままファイルを読み書きします。ファイルを 1 つずつドラッグする必要はありません。「ワークスペース書き込み可」では、このフォルダー内のファイルは毎回の許可なしに変更でき、それ以外の場所への書き込みはこれまでどおり許可が必要です。各メッセージは送信時に選んでいたフォルダーで処理されるため、待機中や許可待ちの間にフォルダーを切り替えても別の場所を変更することはありません。そのメッセージから始めたバックグラウンドタスクも同じフォルダーで作業します。最近使った 10 個のフォルダーはすぐに選べます。アプリのデータフォルダー、ディスクのルート、ホームフォルダーそのものは選べません。ウェブコンソールでは選択中のフォルダーを確認でき、選択や変更はボットが動いているパソコンのデスクトップ版で行います。
- **ZIP の添付：** ZIP（1 件 50 MiB まで）を会話にドラッグして、画像やファイルと一緒に、または ZIP だけで送れます。ボットは何をするか指示されてから中身を確認・展開し、既定では自分のワークスペースに、指示があれば作業フォルダーに展開します。中のプログラムを勝手に実行することはありません。暗号化・分割された ZIP、安全でないパスを含む ZIP、展開後に 200 MiB または 2,000 項目を超える ZIP は、理由を示して拒否します。送信済みの ZIP をクリックすると元のファイルを保存できます。エージェントモードが必要です。

### 改善と修正

- **添付：** 複数のファイルをまとめてドラッグしたとき、追加できるものは追加し、追加できないものはファイル名と理由を 1 行にまとめて知らせます。まとめて全部拒否することはなくなりました。ファイルカードには種類が表示され、長いファイル名でも拡張子が見えたままになります。

## 0.1.45 - 2026-11-22

### 改善と修正

- **コマンドのサンドボックス（Linux）：** ボットが実行するコマンドは bubblewrap のサンドボックス内でのみ動くようになりました。bubblewrap がインストールされていない場合や、システムが名前空間の作成を許可していない場合は、理由と対処方法（bubblewrap のインストール、または許可）を示してコマンドを拒否します。書き込みだけを制限し、コマンドからアプリのデータディレクトリを読めてしまうサンドボックスに黙って切り替えることはなくなりました。フルアクセスのボットには影響しません。公式 Docker イメージでは、既定のオプションで起動したコンテナーが bubblewrap に必要な名前空間を作れないため、これまでどおりそのサンドボックスを既定で許可しています。許可しない場合は `-e AMB_ALLOW_LANDLOCK=0` を付けてください。
- **コマンドライン版のアクセストークン：** `npm start` で実行する場合も、ローカルコンソールを開くにはアクセストークンが必要になりました。ターミナルから起動すると、トークン付きのアドレスを一度表示します。ブラウザーで一度開けば記憶されます。トークンはデータディレクトリの `ui-token` にも保存され、`npm run bot` は自動で読み取ります。デスクトップ版と Docker の使い方は変わりません。

## 0.1.44 - 2026-11-20

### 改善と修正

- **画像の添付：** 会話にドラッグまたは貼り付けたときに対応していない形式として拒否されていた画像を、追加できるようになりました。拡張子と実際の形式が一致しない画像（.jpg として保存された PNG や WebP など）、スマートフォンで撮影した、画像の後ろに追加データが付いた JPEG やモーションフォト（静止画の部分だけを使います）、拡張子が .jfif / .jpe の画像です。どうしても追加できない画像には、Markdown・HTML・TXT を使うようにではなく、PNG または JPG に変換するように案内します。
- **プレビューの安全性：** ボットが生成したウェブページをプレビューするとき、ページ内のスクリプトは同じフォルダーにある他のファイルの内容を読めなくなりました（fetch は使えません）。スタイル、スクリプト、画像、フォントはこれまでどおり読み込まれます。JSON などのデータファイルはプレビュー中のページに提供されなくなったため、必要なデータは HTML に埋め込むか、スクリプトとして用意してください。
- **アプリ内アップデート：** macOS で「再起動して更新」を押したあと、インストール中に「AnyModelBot で問題が発生しました」というウィンドウが表示されなくなりました。この修正は 0.1.44 から有効です。以前のバージョンから 0.1.44 に更新するときは一度だけ表示されることがありますが、更新は正常に完了します。

## 0.1.43 - 2026-11-20

### 新機能

- **画像とファイルの添付：** 会話にスクリーンショットや画像を貼り付けたり、画像やテキストファイル（Markdown、HTML、TXT、CSV、JSON、コードなど）をドラッグしたりして、メッセージと一緒に送れます。添付だけでも送信できます。画像は画像に対応したモデルへ渡され、ファイルは全文がモデルに渡されます。サムネイルをクリックすると拡大表示できます。1 メッセージにつき添付は最大 8 件（うち画像は最大 4 枚）、1 件 10 MiB までです。現在のモデルが画像に対応していない場合はその旨が表示されます。PDF、Office 文書、圧縮ファイル、音声・動画にはまだ対応していません。
- **要望とフィードバック：** 「フィードバック」が「要望とフィードバック」になり、「利用シーンと提案」「問題の報告」「法人・提携」の 3 つに分かれました。下書きはそれぞれ保存されます。連絡先は、その送信について同意にチェックした場合だけ添付されます。ログもチェックした場合のみで、送信前に全文を確認できます。「発見」に法人向けシーンのセクションが加わりました。

### 改善と修正

- **パソコン上のファイル整理：** デスクトップなどのフォルダーの整理を頼んでも、先に「アクセシビリティ」や「画面収録」を求めなくなりました。ワークスペース外の操作はこれまでどおり先に承認を求めます。デスクトップアプリの操作が本当に必要でシステム権限が足りないときは、会話に権限カードが表示され、そこから有効にできます。
- **プレビュー：** プレビューにフォーカスがあるとき、Cmd+W / Ctrl+W は現在のタブだけを閉じます。空のプレビューと「+」メニューに、この会話で開いたファイルが並びます。
- **スキル：** 「スキルとして保存」は直近に完了した依頼を既定で下書きにします。下書きカードでの選択は編集後も保持され、インポート後の通知とカードが「読み込み中」のままになりません。
- **会話とタスク：** 内容や入力欄が高くなっても会話は最下部に追従し、メモやカードが入力欄に隠れません。ボットの「タスク」タブに他のボットから届いた依頼が、送り主とともに表示されます。

## 0.1.40 - 2026-11-15

### 新機能

- **タスクライブラリ：** 「スケジュール」に、ニュース、仕事、学習、生活、家計向けのタスクを 20 件追加しました。タスクを選び、必要な項目、ボット、送信先を設定すればオンにできます。チャットから作成を頼むこともできます。チェック型は先に一度試せて、結果は試行画面と実行記録にだけ表示され、チャットには送信されません。実行にはパソコンとアプリの起動が必要です。
- **ファイルプレビュー：** コードの行番号、構文の色分け、折り返し、JSON の整形と折りたたみ、CSV / TSV の表表示、並べ替え、検索、文字コード切り替えに対応しました。Markdown は画像、タスクリスト、目次、ソース表示、画像は拡大縮小と移動、HTML はプレビューとソースの切り替えができます。

### 改善と修正

- **プレビューの操作と更新：** タブに種類別アイコンと右クリックメニューを追加し、「+」から会話で受け取ったファイルを選べます。アプリ全体への拡大、表示・倍率・折り返し設定の保存、ファイル変更時の更新に対応。デスクトップでは名前を付けて保存、フォルダーで表示、HTML をブラウザーで開く操作ができます。
- **ルールの日時と結果：** 毎年のリマインダーと、毎月・毎年の日付より数日前の通知に対応。ライブラリのチェックは複数行の要約を送れます。試行の費用は月の利用額に含まれ、よく使う cron の時刻表示も読みやすくなりました。
- **公式サイト：** コミュニティの文字メニューをホバーやキーボードのフォーカスで開けます。ホームの機能欄を整理し、変更履歴には公開済みのバージョンだけを表示します。

## 0.1.39 - 2026-11-15

### 新機能

- **入れたらすぐ使い方がわかります：** スキルの ZIP をインポートしたときや、「スキルとアプリ」でアプリをボットに割り当てたとき、通知の下に「こう言ってみましょう」の例が出て、「入力欄に入れる」か「コピー」を選べます。

### 改善と修正

- **新しい会話がすぐ始まります：** 右上の新規ボタン、「+」メニューの「新しい会話」、または /new の入力で、すぐに新しい会話に切り替わり、会話には「新しい会話を始めました」の区切り線が残ります（再読み込みや再起動後も同じ位置にあります）。「/new」の吹き出しが出て「思考中」のまま止まることはなくなりました。それまでの話は引き継ぎメモとして裏でまとめ、新しい会話の最初のメッセージは最大 8 秒だけそれを待ちます。返信中は新規ボタンがグレーになります。チャットアプリで /new を送ってもすぐ返信します。
- **アカウント欄に名前とアイコンを表示：** Modelflare にログインすると、左下とアカウントメニューにニックネームとアイコンが表示されます（ニックネームがなければ自分で設定したユーザー名、次にメールアドレス。アイコンがなければ名前の最初の文字）。「Modelflare アカウント」のままになることはなくなり、再起動時は前回の名前をすぐ表示します。
- **処理経過にどのツールを使ったかを表示：** アプリはツールごとに 1 行、たとえば「Notion · ページを検索 を使用中」と表示し、返信が終わると「使用：Notion · ページを検索、Notion · ページを読む」にまとまります。
- **スキル一覧が見やすく：** 「アプリとスキル › スキル」をカード表示にしました。作者のアイコンはまず頭文字を表示し、読み込めたらふわっと切り替えて端末に保存するので、次回はすぐ表示されます。「GitHub ↗」と「インストール指示をコピー」は常に表示され、タイトルが狭くなることはありません。
- **設定で押せるものがひと目でわかります：** 設定とボット設定の操作を小さなピル型ボタンにし、削除・解除・ログアウトは赤字にしました。「表示」だけの行は行全体を押せます。1 行のボタンは最大 2 つで、それ以外は「⋯」にまとめます。
- **選択ボックスと細かな修正：** 「自分の API キーを使う」ページの「サービス」とプレビューの切り替えボックスは、矢印が右端に固定され、行のどこを押しても開きます。追加したスキルがまだ有効になっていないときの表記を「次のメッセージから有効」に統一しました。サイドバーのまだ使っていない内蔵ボットで、ホバー時の「⋯」が「新着」の点に重ならなくなりました。

## 0.1.38 - 2026-11-15

### 新機能

- **実際のモデルに自動で戻す：** 以前選んでいた「auto/…」のモデル（全体の既定、ボットの既定、チャット内で切り替えたもの）は、起動時に対応する実際のモデルへ自動で切り替わります。見つからなければ既定のモデルに戻します。

### 改善と修正

- **モデル一覧に「auto/…」が出なくなりました：** 同じモデルを複数の提供元が扱うとき（ボットに個別の予算を設定した場合や、Modelflare とは別に公式 API キーを登録した場合など）、元のモデルと見分けのつかない「auto/モデル名」という項目が一覧に増え、選ぶとモデルが存在しないためリクエストが失敗していました。今後は表示も送信もしません。

## 0.1.37 - 2026-11-15

### 新機能

- **わたしについて：**「チームメモリ」は「わたしについて」になり、すべてのボットで共有するあなた自身のことを入れておく場所になりました。どのボットとのチャットでも一度言えば（例：「わたしは Melody です」）全ボットが覚えます。返信の下に 1 行表示され、取り消せます。住所・電話番号・メールは保存前に確認し、あなたが編集した行はボットが元に戻さず、削除した行を勝手に書き戻すこともありません。「設定 › わたしについて」で確認・編集でき、過去 30 日の変更はどれも取り消せます。以前のチームメモリは自動で移行されます。
