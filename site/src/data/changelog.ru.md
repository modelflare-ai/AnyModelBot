## 0.1.48 - 2026-11-25

### Новое

- **Импорт навыков с этого компьютера:** в настольном приложении можно за один раз импортировать навыки, уже установленные на компьютере для других инструментов (Claude Code, Codex, Cursor, CodeBuddy и др.). Шесть привычных мест вроде `~/.claude/skills/` просматриваются автоматически, а через «Выбрать папку…» можно указать папку навыка или проект; пока вы не выберете навыки и не нажмёте «Далее», видны только папки и имена файлов. На странице проверки для каждого навыка указано: можно импортировать, уже есть, то же имя с другим содержимым (по умолчанию пропускается или сохраняется отдельно) или несовместим — с причиной. Импорт никогда не запускает скрипты; навыки с возможными личными файлами или ограничениями вызова, которые приложение не может сохранить так же, не импортируются. Если открыть импорт из настроек бота, навыки по умолчанию сразу включаются в этом боте.
- **Моя библиотека навыков:** в меню аватара появилась «Моя библиотека навыков» — по одной копии каждого навыка на этом компьютере, с поиском, содержимым и списком ботов, которые его используют. В настройках бота › «Навыки» появилось «Добавить из библиотеки…», и каждый переключатель влияет только на этот бот. Навыки, установленные из ZIP или GitHub, и сохранённые вами тоже есть в библиотеке — импортировать их заново не нужно.

### Улучшения и исправления

- **Общие навыки сообщают, кого затронет изменение:** при замене через ZIP или ссылку GitHub навыка, которым пользуются несколько ботов, или при обновлении навыка из «Моих навыков», включённого в нескольких ботах, называются остальные боты, которые получат изменения.
- **Удаление бота больше не удаляет его навыки:** установленные в нём навыки остаются в «Моей библиотеке навыков», их можно добавить в другой бот или убрать из библиотеки.

## 0.1.47 - 2026-11-23

### Новое

- **Изображения как референсы для генерации:** если вы вошли в аккаунт Modelflare и добавили изображения в личный чат с ботом, рядом со счётчиком вложений появляется переключатель «Использовать как референсы для генерации» (по умолчанию выключен). Когда он включён, изображения из этого сообщения становятся референсами в порядке показа; модель, выбранная справа внизу, создаёт изображение, и результат приходит в тот же чат. Само добавление изображений никогда не запускает платную генерацию. Если текущая модель так не умеет, её возможности пока нельзя проверить или изображения выходят за ограничения модели по количеству, формату или размеру, над полем ввода появляется пояснение, а ссылка «Смените модель» в нём открывает привычный список моделей. Подтверждение стоимости работает как раньше (каждый раз или когда оценка выше $0.5), а неподтверждённый результат никогда не повторяется автоматически. Нужны сведения о возможностях модели от Modelflare; если их нельзя проверить, ничего не отправляется. Со своими ключами API пока недоступно.
- **Выбор моделей генерации изображений в списке моделей:** после входа в аккаунт список моделей справа внизу показывает и модели генерации изображений, доступные вашему аккаунту. Выберите одну и опишите нужную картинку — модель для диалога не используется.

### Улучшения и исправления

- **Генерация изображений только выбранной моделью:** после входа в аккаунт, если попросить бота нарисовать что-то обычными словами, он использует только модель, выбранную справа внизу. Если она не умеет создавать изображения или её возможности нельзя проверить, бот объяснит причину и попросит сменить модель, а не переключится на отдельную модель изображений по умолчанию (настройка «Модель изображений по умолчанию» после входа скрыта). При подключении только по ключу API ничего не меняется.

## 0.1.46 - 2026-11-22

### Новое

- **Рабочая папка:** в настольном приложении выберите папку над полем ввода, и бот будет работать с файлами прямо на месте, без перетаскивания по одному. С доступом «рабочая папка» бот может менять файлы в этой папке, не спрашивая каждый раз; запись в другие места по-прежнему требует вашего разрешения. Каждое сообщение сохраняет папку, выбранную при отправке: если сменить папку, пока сообщение ждёт в очереди или разрешения, оно не перейдёт в другое место, а фоновые задачи, начатые из него, работают в той же папке. 10 недавних папок выбираются в один щелчок; папку данных приложения, корень диска и саму домашнюю папку выбрать нельзя. В веб-консоли видна выбранная папка, а выбирать и менять её нужно в настольном приложении на компьютере, где работает бот.
- **ZIP-вложения:** перетащите ZIP (до 50 МиБ) в чат и отправьте вместе с изображениями и файлами или отдельно. Бот заглядывает внутрь или распаковывает архив только после того, как вы скажете, что делать: по умолчанию — в свою рабочую папку, по вашей просьбе — в рабочую папку проекта; сам ничего из архива не запускает. Зашифрованные и многотомные ZIP, архивы с небезопасными путями или больше 200 МиБ либо 2000 элементов после распаковки отклоняются с указанием причины. Щёлкните отправленный ZIP, чтобы сохранить исходный файл. Нужен режим агента.

### Улучшения и исправления

- **Вложения:** если перетащить несколько файлов, подходящие добавляются, а остальные перечисляются в одной строке с причиной — вся партия больше не отклоняется целиком. Карточки файлов показывают тип и сохраняют видимым расширение у длинных имён.

## 0.1.45 - 2026-11-22

### Улучшения и исправления

- **Песочница для команд (Linux):** команды, которые выполняет бот, теперь запускаются только в песочнице bubblewrap. Если bubblewrap не установлен или система не разрешает ему создавать пространства имён, команда отклоняется с указанием причины и способа исправить (установить bubblewrap или разрешить ему это), а не переходит незаметно в песочницу, которая ограничивает только запись и позволяет командам читать папку данных приложения. На ботов с полным доступом это не влияет. Официальный образ Docker по-прежнему разрешает такую песочницу по умолчанию, потому что контейнер, запущенный с параметрами по умолчанию, не может создать пространства имён, нужные bubblewrap; чтобы запретить её, добавьте `-e AMB_ALLOW_LANDLOCK=0`.
- **Токен доступа в версии для командной строки:** при запуске через `npm start` для локальной консоли теперь тоже нужен токен доступа. При запуске из терминала один раз выводится адрес с токеном; откройте его в браузере, и браузер его запомнит. Токен также сохраняется в файле `ui-token` в папке данных, и `npm run bot` читает его автоматически. Настольное приложение и Docker работают как прежде.

## 0.1.44 - 2026-11-20

### Улучшения и исправления

- **Вложения-изображения:** некоторые изображения при перетаскивании или вставке в чат отклонялись как неподдерживаемый формат; теперь они добавляются: изображения, у которых расширение не совпадает с настоящим форматом (например, PNG или WebP, сохранённые как .jpg), JPEG с телефона с дополнительными данными после изображения и «живые» фото (используется только неподвижный кадр), а также изображения с расширением .jfif или .jpe. Если изображение действительно нельзя добавить, приложение предложит преобразовать его в PNG или JPG, а не использовать Markdown, HTML или TXT.
- **Безопасность предпросмотра:** при предпросмотре веб-страницы, созданной ботом, скрипты страницы больше не могут читать содержимое других файлов из той же папки (fetch заблокирован); стили, скрипты, изображения и шрифты загружаются как прежде. Файлы данных, например JSON, больше не отдаются страницам в предпросмотре — встраивайте данные в HTML или подключайте их как скрипт.
- **Обновление в приложении:** на macOS после нажатия «Перезапустить и обновить» во время установки больше не появляется окно «В работе AnyModelBot возникла ошибка». Исправление действует начиная с 0.1.44: при обновлении до 0.1.44 с более старой версии окно ещё может появиться один раз, обновление при этом завершится нормально.

## 0.1.43 - 2026-11-20

### Новое

- **Вложения: изображения и файлы:** вставьте в чат снимок экрана или изображение либо перетащите изображения и текстовые файлы (Markdown, HTML, TXT, CSV, JSON, код и другие) и отправьте их вместе с сообщением. Можно отправить и одни вложения. Изображения передаются моделям, которые умеют их видеть, а файлы — полным текстом; по щелчку на миниатюре изображение открывается крупно. В одном сообщении до 8 вложений, из них не более 4 изображений, каждое до 10 МиБ. Если текущая модель не поддерживает изображения, приложение об этом сообщит. PDF, документы Office, архивы, аудио и видео пока не поддерживаются.
- **Запросы и отзывы:** «Обратная связь» стала разделом «Запросы и отзывы» с тремя категориями: «Сценарии и идеи», «Проблемы», «Бизнес и партнёрство». У каждой свой черновик. Контактные данные прикладываются, только если вы отметили согласие для этой отправки, журналы — только если вы их отметили; перед отправкой можно просмотреть всё содержимое. В «Обзоре» появился раздел бизнес-сценариев.

### Улучшения и исправления

- **Наведение порядка в файлах:** если попросить бота разобрать файлы на рабочем столе или в других папках, он больше не требует сначала включить «Универсальный доступ» или «Запись экрана»; действия вне рабочей области по-прежнему требуют вашего одобрения. Когда задаче действительно нужно управлять приложением на рабочем столе и не хватает системного разрешения, в чате появляется карточка, где его можно включить.
- **Предпросмотр:** когда фокус в предпросмотре, Cmd+W / Ctrl+W закрывает только текущую вкладку; пустой предпросмотр и меню «+» показывают файлы, открытые в этом чате.
- **Навыки:** «Сохранить как навык» по умолчанию берёт последнюю завершённую задачу; выбор на карточке черновика сохраняется после правки; уведомление об импорте и карточки больше не остаются в состоянии «Загрузка».
- **Чат и задачи:** чат остаётся внизу, когда растёт содержимое или поле ввода, поэтому заметки и карточки не прячутся за полем ввода; на вкладке «Задачи» бота видны дела, присланные другими ботами, с указанием отправителя.

## 0.1.42 - 2026-11-18

### Новое

- **Отзывы прямо из приложения:** окно обратной связи открывается из пункта «Обратная связь» в меню аккаунта, кнопкой «Сообщить об этой проблеме» под ошибкой в беседе, а также в «Настройки → Диагностика» и «Настройки → О приложении». Выберите «Проблема», «Предложение» или «Другое», напишите пару строк и отправьте. Версия и сведения о системе прикладываются всегда, а при открытии из ошибки — и сама ошибка. Диагностика прикладывается, только если отметить её; перед отправкой можно посмотреть весь текст, беседы и снимки экрана не прикладываются. Если вы вошли в Modelflare, отзыв становится обращением в вашем аккаунте: ответы поддержки приходят на почту и видны на странице обращений Modelflare, не больше 3 в день. Без входа отзыв можно отправить через GitHub или по почте — всё будет заполнено за вас.

### Улучшения и исправления

- **Ссылки на почту:** в настольном приложении ссылки на почту в беседе открываются в почтовой программе системы. Раньше нажатие на них ничего не делало.

## 0.1.40 - 2026-11-15

### Новое

- **Библиотека задач:** на странице расписания появились 20 готовых задач для новостей, работы, учёбы, быта и финансов. Выберите задачу, заполните поля, укажите бота и получателя, затем включите её. Создать правило из библиотеки можно и через чат. Проверки можно сначала попробовать: результат появится только в окне пробы и журнале запусков, без отправки в чат. Компьютер и приложение должны быть включены.
- **Просмотр файлов:** для кода доступны номера строк, подсветка синтаксиса и перенос строк; для JSON — форматирование и сворачивание; для CSV / TSV — таблица, сортировка, поиск и выбор кодировки. Markdown поддерживает изображения, списки задач, оглавление и исходный текст, изображения — масштабирование и перемещение, HTML — переключение между просмотром и кодом.

### Улучшения и исправления

- **Управление просмотром:** у вкладок есть значки типов файлов и контекстное меню, а «+» показывает файлы, полученные в беседе. Панель можно развернуть на всё окно; настройки вида, масштаба и переноса сохраняются, при изменении файла просмотр обновляется. В настольной версии доступны сохранение под другим именем, показ в папке и открытие HTML в браузере.
- **Расписание и результаты правил:** добавлены ежегодные напоминания и уведомления за несколько дней до ежемесячной или ежегодной даты. Проверки из библиотеки могут отправлять многострочные сводки, расходы на пробу учитываются за месяц, а типичные расписания cron отображаются понятнее.
- **Сайт:** текстовое меню сообщества открывается при наведении или фокусе с клавиатуры. Раздел возможностей на главной упрощён, история изменений показывает только опубликованные версии.

## 0.1.39 - 2026-11-15

### Новое

- **Сразу понятно, что написать:** после импорта ZIP-навыка или назначения приложения боту в «Навыках и приложениях» под уведомлением есть пример «Попробуйте написать» с кнопками «Вставить в сообщение» и «Копировать».

### Улучшения и исправления

- **Новый разговор начинается сразу:** кнопка нового разговора, пункт «Новый разговор» в меню «+» или команда /new сразу открывают новый разговор и оставляют в чате разделитель «Начат новый разговор» (он остаётся на месте после перезагрузки и перезапуска). Пузыря «/new», который зависал на «Думает», больше нет. На чём вы остановились, записывается в фоне в заметку для продолжения, и первое сообщение нового разговора ждёт её не дольше 8 секунд. Пока идёт ответ, кнопка неактивна. В мессенджерах /new тоже отвечает сразу.
- **Ваше имя и аватар в разделе аккаунта:** после входа в Modelflare внизу слева и в меню аккаунта показываются ваш никнейм и аватар (если никнейма нет — ваше имя пользователя, затем email; если нет аватара — первая буква имени), а не «Аккаунт Modelflare». После перезапуска сразу видно прошлое имя.
- **В ходе работы видно, какой инструмент использовался:** для приложений — по строке на каждый инструмент, например «Использует Notion · Поиск страниц», а после ответа это сворачивается в «Использовано: Notion · Поиск страниц, Notion · Чтение страницы».
- **Понятнее список навыков:** «Приложения и навыки › Навыки» теперь показаны карточками. Аватары авторов сначала показываются инициалами, плавно появляются после загрузки и сохраняются на устройстве, так что в следующий раз видны сразу. «GitHub ↗» и «Скопировать запрос» видны всегда и не сужают заголовок.
- **В настройках сразу видно, что можно нажать:** действия в настройках и настройках бота стали небольшими кнопками-капсулами, а «Удалить», «Убрать» и «Выйти» — красными. Строку с единственным «Открыть» можно нажать целиком, и в строке не больше двух кнопок, остальное — в «⋯».
- **Списки выбора и мелкие исправления:** у «Сервиса» на странице «Использовать свой API-ключ» и у переключателя в предпросмотре стрелка всегда у правого края, а открыть список можно из любого места строки. Добавленный, но ещё не включившийся навык теперь подписан «Заработает со следующего сообщения». У встроенных ботов, которыми вы ещё не пользовались, «⋯» в боковой панели больше не закрывает точку «новое».

## 0.1.17 - 2026-11-03

### Новое

- **Пять языков:** к упрощённому китайскому и английскому добавлены японский, корейский и русский. Переведены интерфейс приложения, меню в трее, системные сообщения, подсказки авторизации, сайт и документация. Язык можно выбрать при первом запуске, в настройках или палитре команд.

- **Страница для партнёров:** на сайте появились описание сотрудничества и форма заявки. Если API для приёма заявок не настроен, форма явно предлагает связаться по электронной почте и не сообщает об успешной отправке, которой не было.

### Улучшения и исправления

- Ошибки авторизации Feishu и Notion отображаются на текущем языке. При отказе локального прокси в подключении появляется подсказка с возможными действиями, а исходная ошибка сохраняется.
- Обновлены эффекты неба, страница загрузки и мобильная вёрстка сайта. Добавлены изображения для публикации ссылок, языковые метки для поисковиков и страницы 404 для каждого языка.

## 0.1.16 - 2026-11-02

## 0.1.15 - 2026-11-02

### Новое

- **Общие аккаунты для всех ботов:** добавьте аккаунты мессенджеров и Notion один раз в разделе «Настройки › Подключения», и ими смогут пользоваться все боты. У каждого сервиса может быть несколько аккаунтов со своими именами.
- **Смена бота из чата:** отправьте `/bot` в мессенджере, чтобы увидеть ботов, и `/bot name`, чтобы переключиться. Выбор сохраняется для этого чата; повторять команду каждый раз не нужно. Каждый бот также знает об остальных и может ответить на вопросы о них.
- **Telegram, Slack и Discord:** подключаются по токену без публичного адреса; изображения и файлы передаются в обе стороны.
- **Notion:** подключение через авторизацию одним нажатием или токен. Боты могут искать, читать, создавать и изменять страницы, запрашивать базы данных. Удалять страницы они не могут.
- **Чтение сообщений Feishu:** авторизуйтесь по QR-коду и попросите любого бота, например, «проверь мой второй Feishu». Он читает чаты и ищет сообщения от вашего имени, только для чтения.
- **Добавление Feishu сканированием:** при добавлении аккаунта чата можно создать приложение по QR-коду вместо ввода App ID и Secret.

### Улучшения

- **Поиск больше не требует ключа DeepSeek:** по умолчанию он бесплатный; можно выбрать Tavily, Exa, Bocha, Zhipu или свой SearXNG.
- **Персонажи отделены от ролей:** аватар определяет только внешний вид и не меняется при выборе шаблона.

### Изменения

- Настройка каналов перенесена из панели каждого бота в раздел «Настройки › Подключения». Существующие аккаунты переносятся автоматически без повторного входа; по умолчанию отвечает тот же бот.
- Владелец и разрешённые пользователи теперь относятся к аккаунту. Пользователь с доступом к нему может общаться с любым ботом. Удаление бота больше не затрагивает аккаунты.
